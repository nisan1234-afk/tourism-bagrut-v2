# תיירות לבגרות 2.0

מערכת לימוד מלאה לתלמידים ולמורים, כחלק מכיתה פלוס.

> סטטוס: פיתוח מוקדם. המערכת אינה מחליפה עדיין את `tourism11` הפעיל.

## חזון

מוצר אחד ואחיד הכולל:

- גרסה פתוחה ללא התחברות.
- חוויית תלמיד עם התקדמות, מצגות, תמונות, בחנים ובוט.
- חוויית מורה עם מצב כיתתי, ניתוח קשיים וסטודיו תוכן חזותי.
- יחידות לימוד מלאות המבוססות רק על חומרי המקור המאושרים ב-Google Drive.
- שילוב טבעי של מאגר התמונות והתרגול מתוך `jerusalem-tour`.
- חיבור לזהות, לתפקידים ולשיוך המקצועי הקיימים בכיתה פלוס.

## עקרונות

- Drive הוא מקור האמת לתוכן.
- אין שימוש במידע חיצוני ליצירת תוכן או שאלות.
- תוכן חדש נשמר כטיוטה ודורש אישור מורה לפני פרסום.
- האתר הקיים נשאר פעיל עד לאישור והשלמת הגרסה החדשה.
- חוויית המחשב והמובייל נבדקות בנפרד.
- כל עבודה של Codex או Claude מתועדת ב-`AI_WORKLOG.md`.

## תהליך הפיתוח

1. מערכת עיצוב ושלד ניווט.
2. יחידת פיילוט מלאה: מישור החוף.
3. מצגת מוטמעת ותרגול תמונות.
4. חוויית תלמיד ומעקב התקדמות.
5. דשבורד מורה וניתוח כיתתי.
6. סטודיו עריכה ובניית יחידות מבוססת חומרים.
7. בדיקות וחיבור לכיתה פלוס.
