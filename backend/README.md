# backend/ — הבקאנד של כיתה פלוס ותיירות לבגרות (Apps Script)

זה **המקור היחיד** של הקוד שרץ ב-Apps Script. מ-04.09.2026 אין עורכים בעורך של גוגל ישירות:
כל שינוי הוא commit כאן, ו-GitHub Action (`.github/workflows/deploy-backend.yml`) מפרסם
גרסה חדשה על ה-deployment הקיים. כתובת ה-API לא משתנה לעולם.

## קבצים

| קובץ | מה זה |
|---|---|
| `code.gs` | כיתה פלוס: כניסה, תפקידים, מקצועות, תיירות דיגיטלית (קבוצות, שיעורים, ממצאים), Gemini, FCM |
| `bagrut.gs` | תיירות לבגרות: תלמידים, התקדמות, תשובות פתוחות, בוט, עריכת תוכן, טעויות, זיהוי אתרים |
| `appsscript.json` | מניפסט: V8, Drive Advanced Service, web app פתוח לאנונימי, רץ כבעל הפרויקט |
| `seed_*.gs`, `setup_*.gs` | סקריפטי הגירה חד-פעמיים מהעבר. לא נקראים מ-`doPost`. מועמדים להעברה לארכיון |

## איך פורסים

1. commit ל-`main` שנוגע ב-`backend/`.
2. ה-Action: בדיקת תחביר → צילום של המקור שבעורך (רשת ביטחון) → `clasp push` → `clasp deploy -i <deployment>` → קריאת אימות ל-API.
3. אם משהו נכשל, הקוד בעורך כבר עודכן אבל **הגרסה הפרוסה לא** (deploy הוא הצעד האחרון). לתקן ולדחוף שוב.

## מה צריך להיות מוגדר פעם אחת

- Apps Script API מופעל בחשבון: https://script.google.com/home/usersettings
- secret בריפו בשם `CLASPRC` עם תוכן `~/.clasprc.json` שנוצר אחרי `clasp login` במחשב.

## סודות

מפתח Gemini ומפתח Firebase נמצאים ב-Script Properties של הפרויקט, לא בקוד. מזהי גיליונות
ותיקיות כן בקוד; הם לא מעניקים גישה בלי הרשאת דרייב.

## איך מוודאים מה פרוס

Manage deployments בעורך מציג לכל גרסה תיאור בפורמט `git <hash> · main`. ההאש הזה הוא
הקומיט שממנו נפרס. בהמשך יתווסף endpoint שמחזיר את זה ישירות.
