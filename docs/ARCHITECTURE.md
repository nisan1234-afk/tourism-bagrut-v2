# ארכיטקטורה ראשונית

## גבולות המערכות

### כיתה פלוס

אחראית על:

- התחברות Google.
- זהות ותפקיד.
- שיוך תלמידים ומורים למקצוע.
- כניסה אחידה וסיכום התקדמות בין מקצועות.

### תיירות לבגרות 2.0

אחראית על:

- יחידות ותוכן.
- מצגות מוטמעות.
- מאגר תמונות ותרגולים.
- בחנים ותשובות פתוחות.
- התקדמות מפורטת.
- תובנות ותרגול מותאם.
- סטודיו מורה וטיוטות.

## מקורות אמת

- תוכן פדגוגי: תיקיית Drive `אתר תירות אלוני הבשן`.
- זהות והרשאות: כיתה פלוס.
- קוד חדש: המאגר הזה.
- האתר הפעיל עד למעבר: `tourism11`.
- תמונות קיימות: `jerusalem-tour`.
