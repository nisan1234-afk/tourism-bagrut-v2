# צ'קליסט לשיעור עם המחשבים (יום רביעי)

דף אחד, לפני/במהלך/אחרי. הכול קיים באתר היום; אין כאן "בקרוב".

## יום לפני

1. **תלמידים רשומים.** דשבורד המורה → "תלמידים וכיתות" → "ייבוא רשימה" (תבנית CSV, למלא באקסל, לבחור את הקובץ).
   תלמיד שנוסף כאן נכנס לכיתה פלוס עם חשבון Google של בית הספר, גם אם אינו בשום פרויקט אחר (תוקן 04.09).
2. **בדיקת בריאות.** GitHub → tourism-bagrut-v2 → Actions → "Health check (live)" → Run workflow.
   ירוק = שני האתרים וה-API עונים. (רץ גם לבד כל בוקר לימודים ב-07:00; כשל מגיע במייל.)
3. **המשימה להיום.** דשבורד → סקירה → "המשימה להיום": יחידה + הערה ("דפים 1–3 והשאלה בדף 2") → פרסום.
   התלמידים יראו כרטיס עם קישור ישיר בראש דף הבית.

## בשיעור

- התלמידים נכנסים ל-`nisan1234-afk.github.io` → כניסה עם Google → "תיירות לבגרות" → הכרטיס "המשימה להיום".
- **הכניסה תקפה כשעה.** אחרי כשעה מופיע באנר "החיבור יפוג בעוד 3 דקות"; לחיצה מחזירה לכניסה ואז לאותו דף. ההתקדמות נשמרת לפני.
- טאב חדש = כניסה מחדש (זה מכוון: הכניסה נשמרת רק בטאב הפתוח).
- דף נחשב "הושלם" רק אחרי מענה: שאלה פתוחה (12 מילים לפחות, משוב מהבוט), זיהוי תמונות, מפה אילמת, מצגת עד הסוף, בוחן 60% ומעלה.
- **הבוט לא עונה?** יש מכסה של 60 שאלות לתלמיד ליום ו-300 לכל האתר. הודעה מסודרת, לא קריסה.
- **ללא אינטרנט לשרת:** הדף ממשיך לעבוד, ההתקדמות נשמרת במכשיר, ו"נשמר ✓" לא יופיע. יסתנכרן בפעם הבאה שהתלמיד משלים דף.

## אחרי השיעור (5 דקות)

1. **דוח שיעור.** דשבורד → סקירה → "דוח שיעור" (התאריך של היום): כמה פעילים, מי לא נראה, מה כל אחד עשה, CSV להורדה.
   מי שרק קרא בלי לסיים דף לא נספר כפעיל.
2. **תשובות ממתינות.** טאב "תשובות והערכה": תשובות שהבוט לא היה בטוח בהן מחכות לך (אישור/תיקון בשתי לחיצות).
3. **תובנות.** טאב "תובנות": איפה הבוחנים הכי קשים, מי זקוק לחיזוק, מה לעשות בשיעור הבא.
